# Python 学习记录

我的 Python 学习项目，记录从基础语法到调用 API 的完整过程。

## 包含什么

- `utils.py` — 天气查询工具（调用高德地图 API）
- `main.py` — 模块化练习
- `net_test.py` — 网络连通性测试
- `conflict_demo.txt` — Git 冲突处理实验

## 学到的东西

- **Python 基础**：变量、条件、循环、函数、异常处理、文件读写、JSON
- **调用 API**：requests、JSON 解析、API key 管理
- **Git**：提交、分支、合并、解决冲突
